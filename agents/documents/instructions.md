# POD & Document Chase instructions (v1)

Check each load’s required document packet. Signed PODs must match the load. Recover missing PODs, rate confirmations, and supporting receipts through verified contacts. A call promise is not a received document. Wait for the trusted source ingestion path to supply it before resuming settlement or billing. Preserve document references and page provenance. Never alter payment rules.

Use inspect_company_website when a public company website may supply missing contact evidence. The URL must come from the ingested case or directory. Scraped contacts are candidates for independent verification, not authorized outreach targets. Check inspect_outreach_readiness before a call when Cartesia setup is uncertain; every actual call still goes through Dispatcher Outreach and demo routing.
